# icl-dev

Code maison des sites L'Instant Clé et Sexcape Room. Dépôt privé.

- `CLAUDE.md` porte les règles de travail et le contexte technique. À lire d'abord.
- `docs/briefs/` porte les briefs de construction.
- `mu-plugins/` et `themes/astra-child/` portent le code déployé.

Déploiement : SiteGround Site Tools, ou SFTP vers `wp-content/`. Le dépôt n'est jamais déployé tel quel : seuls `mu-plugins/` et `themes/` ont un équivalent sur le serveur.
